# Predicción de Interrupción Escolar mediante Redes Bayesianas y Análisis Correlacional

Repositorio correspondiente a la investigación desarrollada sobre la predicción de interrupción escolar en el CBTis No. 191 de Gutiérrez Zamora, Veracruz.

## Descripción

Este proyecto integra técnicas de análisis estadístico no paramétrico y modelado probabilístico para analizar factores asociados a la interrupción escolar en estudiantes de nivel medio superior.

La investigación utiliza:

- Correlación de Spearman
- Kendall Tau-B
- Redes Bayesianas
- Procesamiento y depuración de bases de datos académicas
- Análisis socioeconómico exploratorio

El objetivo principal es identificar patrones relacionados con el rendimiento académico y estimar probabilísticamente el semestre de interrupción escolar.

## Tecnologías y bibliotecas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- pgmpy
- NetworkX
- SciPy
- Prince

## Estructura del repositorio

### Correlaciones
Scripts utilizados para generar matrices correlacionales de Spearman y análisis académicos.

### Redes_bayesianas
Implementación de modelos probabilísticos mediante Redes Bayesianas utilizando pgmpy.

### Procesamiento
Scripts de preparación, discretización y transformación de datos.

### Mixtos
Análisis exploratorios que integran variables académicas y socioeconómicas.

### Resultados
Visualizaciones, matrices y estructuras generadas durante el análisis.


## Consideraciones éticas

Las bases de datos académicas originales no se incluyen públicamente debido a criterios de confidencialidad y protección de datos institucionales.

Toda información identificable de estudiantes fue excluida del procesamiento utilizado en este repositorio.
